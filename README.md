## 五步闭环（Skill 工作流）

1. **续航圈店** — 输入剩余续航 → 三重过滤（单程 / 往返 / 余量）→ 带「可达 / 紧张 / 回不来」标签的门店卡片
2. **充电即点餐** — 选定门店 → 按充电时长算 ETA 对齐：`T_now = max(0, T_cook + T_queue - T_drive - T_charge_remaining)`，决定「立即点」还是「到店前 N 分钟再点」
3. **配餐 + 优惠** — 充电越久可选越丰盛，自动叠加最优优惠券
4. **下单** — 到店自取（支付由用户在麦当劳 App 完成，诚实边界）
5. **老司机套餐** — 读历史订单，一句「老样子」一键复点

### 用到的麦当劳 MCP 能力

门店查询 · 菜单 · 报价下单 · 优惠券 · 积分 · 订单列表 · 营养表 · 地址（`https://mcp.mcd.cn`，Bearer 鉴权）。

## 车机风 Demo（差异化核心）

单文件、零依赖的**车机中控大屏**模拟，五屏流程：

主屏 → 续航圈店（SVG 地图）→ 充电×取餐双进度环 ETA 对齐动画 → **方控走焦点餐** → 取餐码

全程**键盘方向键 + Enter + Backspace** 模拟方向盘方控走焦（焦点高亮、焦点记忆、零触摸）—— 这是车机工程师的日常手艺，直接变成作品的 demo 卖点，别人做不出这种真实感。

```bash
# 本地预览
cd demo && python3 -m http.server 8080
# 浏览器打开 http://localhost:8080 后用方向键体验
```

## 快速开始（作为 Skill 使用）

1. 在 WorkBuddy 中连接麦当劳 MCP：`https://mcp.mcd.cn`（Streamable HTTP，Bearer Token，于 open.mcd.cn/mcp 领取）
2. 将本仓库的 `SKILL.md` + `scripts/` + `references/` 安装为 WorkBuddy 技能
3. 用自然语言触发，例如：
   - “我剩 120 公里续航，附近哪家麦当劳回得来？”
   - “插枪充电了，35 分钟，帮我点餐让它充好就能取”
   - “老样子，再来一份”

## 目标用户

- **新能源车主 / 车机用户**：充电 30 分钟干等的人，需要「插枪即下单、充好就取餐」的确定性体验
- **通勤族 / 长途司机**：在车机大屏上零触摸、用方控走焦完成点餐，安全又省事
- **麦门信徒 / 效率党**：想要「老样子」一键复点、顺手凑券省钱的车载场景用户
- **开发者**：想看「麦当劳 MCP + 车机第三空间 + 方控走焦交互」玩法落地的人
