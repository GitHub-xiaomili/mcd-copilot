三、Skill 工作流（SKILL.md 中定义）
------------------------------------------------------------------------
触发词示例：充电点餐 / 长途补能 / 还剩 xx 公里 / 跑长途吃什么

流程：
1. 续航圈店
   输入剩余续航/电量 → 调用 MCP 门店查询 → 三重过滤：
   a. 单程可达（去程 ≤ 续航 × 0.8）
   b. 往返可达（去程+回程 ≤ 续航 × 0.8）
   c. 到店后还能继续行程（余量 ≥ 下一段路程）
   输出带"可达/紧张/回不来"标签的门店卡片列表。

2. 充电即点餐
   用户选定门店 → 输入预计充电时长（或目标电量 80% 对应时长）
   → 调用菜单接口取餐品 → charge_eta.py 计算 ETA 对齐：
   T_now = max(0, T_cook + T_queue - T_drive - T_charge_remaining)
   若 T_now <= 0：立即下单；否则提示"到店前 N 分钟再点"。

3. 配餐与优惠
   order_compose.py 按充电时长热量预算配餐（充电越久可选越丰盛），
   自动叠加 query-my-coupons 最优优惠券组合。

4. 下单
   调用 MCP 报价/创建订单（到店自取）。支付由用户完成——
   与大赛其他作品一致的责任边界，诚实且安全。

5. 老司机套餐
   combo_memory.py 读取 order-list 历史订单，统计高频组合，
   下次一句"老样子"一键复点。

保持 MCP 边界干净，demo 数据诚实标注。


五、Demo 网站设计（差异化核心卖点）
------------------------------------------------------------------------
形态：模拟车机中控大屏（深色主题、横屏、大按钮），单文件 HTML，
零依赖，GitHub Pages 可看，本地双击可开。

五个场景屏：
S1 主屏（车机桌面）
   状态栏（时间/电量环/续航）+ 副驾唤醒入口（键盘 Enter 唤出）
S2 续航圈店
   SVG 简化地图 + 门店卡片，带"可达/紧张/回不来"三色标签
S3 充电 × 取餐 ETA 对齐（视觉锤）
   左右双进度环动画：充电 0→80% 与麦麦 ETA 同步推进，
   "充到 80%，麦麦刚好到手"同屏可视化
S4 方控点餐（作者专业背书）
   菜单列表 + 方控走焦：
   - 键盘 ← ↑ ↓ → 导航，Enter = OK，Backspace = 返回
   - 焦点项车机风格高亮放大
   - 返回时焦点回到上次位置（焦点记忆）
   - 底部常驻提示条："用键盘方向键操作，模拟方向盘方控"
S5 取餐完成
   取餐码 + 本单热量/碳排彩蛋卡片

技术：vanilla JS + CSS，模拟数据写死并标注"演示数据"，
方便评委阅读源码。
